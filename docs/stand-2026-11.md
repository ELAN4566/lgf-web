# Stand Websites – Zusammenfassung der Anpassungen (17.11.2026)

## Ausgangslage

wortuhr-, mds- und mvs-Website wurden mit Zeta Producer gepflegt. Ziel: alles in einem
Git-Repo, Texte als Dateien, Publizieren per `git push`, Hosting weiterhin auf den eigenen
Servern, Shop später möglich.

## Aufbau

```
                      GitHub (privat: ELAN4566/lgf-web)
   push main ──→ Action baut alle Sites ──→ Branch deploy
   push test ──→ Action baut alle Sites ──→ Branch deploy-test
                                  ↑
                    git fetch alle 5 min (nur ausgehend, Deploy-Key nur lesend)
                                  │
Internet ─→ dmzsrv 10.1.6.3 ──────┼──→ appsrv 10.1.1.54   :5104  /var/www/wortuhr
            TLS (Let's Encrypt)   ├──→ mvssrv            :5102 mvs, :5107 mds   (später)
            Sicherheits-Header    └──→ mvstestsrv        :5102 mvs, :5107 mds   (später)
```

- **Repo** `C:\Devel\lgf-web`: Astro 7, npm-Workspaces. `packages/shared` (gemeinsames Layout,
  News, Impressum/Datenschutz), `sites/wortuhr|mds|mvs`, `content/news` (gemeinsame News, Feld
  `sites`), `deploy/` (Server-Dateien), `docs/` (diese Dokumente).
- **Build**: GitHub Action `.github/workflows/build-deploy.yml`, Node 24. Ergebnis als
  Orphan-Branch `deploy` bzw. `deploy-test` mit Datei `VERSION`.
- **Abholen**: Pro Server Benutzer `lgfdeploy`, Klon `/opt/lgf-web-deploy`, Skript
  `/opt/lgf-web-deploy-bin/lgf-web-deploy.sh`, Konfiguration `/etc/lgf-web-deploy.conf`
  (`BRANCH`, `SITES`), systemd-Timer alle 5 min. Kopiert per rsync mit `--delay-updates`
  (nie ein halber Stand online), SELinux-Kontext per `restorecon`.

## Anpassungen auf den Servern

### appsrv (10.1.1.54)

- `git` installiert, Benutzer `lgfdeploy` mit Deploy-Key «appsrv» (GitHub, nur lesen).
- `/opt/lgf-web-deploy` (Branch `deploy`), `/etc/lgf-web-deploy.conf`: `SITES="wortuhr"`.
- systemd: `lgf-web-deploy.service` + `.timer` aktiv.
- `/var/www/wortuhr` mit SELinux-Regel `httpd_sys_content_t`.
- nginx: `conf.d/wortuhr.conf` (Port **5104**), `conf.d/00-lgf-robots-map.conf`
  (Testhosts → `X-Robots-Tag: noindex`), `snippets/lgf-security-headers.conf`.
- firewalld: Port 5104 nur von dmzsrv (10.1.6.3). SELinux erlaubte 5100–5109 bereits.
- logrotate nginx: `maxage 30` ergänzt.

### dmzsrv (10.1.6.3)

- `conf.d/wortuhr.conf`: Port 80 → 301 auf https (ACME-Pfad ausgenommen), 443 mit
  Let's-Encrypt-Zertifikat `wortuhr.lgf.ch`, Upstream `appsrv_5104` mit Keepalive, Snippets wie
  `www.conf`. Gleichnamige Sicherheits-Header von appsrv werden ausgeblendet (keine Duplikate).
- logrotate nginx: `maxage 30` ergänzen (Datenschutzerklärung: Logs ≤ 30 Tage).

### DNS (Split-DNS)

- Öffentlich (Solnet): `wortuhr` A 212.101.20.60
- Intern (Samba-AD sdc1/sdc2, Zone lgf.ch): `wortuhr` A 10.1.6.3
  (eingetragen mit RSAT, `runas /netonly /user:LGF1\administrator "mmc dnsmgmt.msc"`)
