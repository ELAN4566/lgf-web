Software

MDS Controller

Der MDS Controller verbindet Digitalzentrale, Decoder und Benutzer. Bedient wird er im Browser – auf dem PC, dem Tablet oder dem Smartphone.

Systemvoraussetzungen

  • PC mit Windows 10 oder Windows 11
  • Alternativ: Raspberry Pi als Kleincomputer für den Controller
  • Internetzugang für Installation und Betrieb
  • Ein gutes WLAN am Ort der Modellbahn – der Access Point sollte bei der Anlage stehen
  • Tablet oder Smartphone für die erstmalige Aufnahme der Decoder ins WLAN

Keine Datenhaltung, kein Backup

Der Controller speichert keine eigenen Daten. Alles kommt aus der MVS-Datenbank oder wird von den Decodern geladen.

Immer aktuell

Neue Versionen werden beim nächsten Start automatisch installiert.

Kosten

Der Betrieb der MDS Controller Software ist kostenfrei.
